# WristGuard

Research-based wrist strain prevention for people who type all day.

- **Browser extension (Chrome, Edge, Brave, Arc):** break reminders that count active typing time, guided wrist exercises, history, and settings.
- **Webcam posture checker:** measures your wrist angle live and scores it against carpal tunnel pressure thresholds. Runs fully on your device. Ships inside the extension and as a standalone website.
- **Research write-up:** `research/WristGuard_Research.pdf`.

## Install the extension

1. Unzip `wristguard-extension.zip`.
2. Open `chrome://extensions` (or `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder.
4. Pin WristGuard to the toolbar. Allow notifications when asked.

## Run the website

The checker needs a secure context (https or localhost). It will not work from `file://`.

- Local: `cd web && python3 -m http.server 8000`, then open http://localhost:8000
- Hosted: run `./build.sh`, then upload `web/` to Netlify or Vercel, or use the GitHub Pages workflow below.

## Testing

Run `npm test` for the automated tests. See [TESTING.md](TESTING.md) for how to trigger reminders instantly and a full manual checklist.

## Publish the posture checker on GitHub Pages

In your repo go to **Settings > Pages** and set **Source** to **GitHub Actions**. Every push to `main` then builds and publishes the checker at `https://<your-username>.github.io/<repo-name>/`.

## How it works

**Reminder engine (`background.js`)**
- A 1-minute alarm adds to two counters only while you are active (`chrome.idle`). Each gap is capped at 90 s, so a sleeping laptop does not count.
- Microbreak every 20 active minutes (30 s). Exercise routine every 60 active minutes (about 4 min).
- Two-stage reminder: a notification with Start and Snooze first. If ignored for 3 minutes, a focused break window opens.
- Idle time counts as rest: 60+ s away resets the microbreak timer; 5+ min away resets both and logs a natural rest.
- Closing the break window counts as a skip. Pause for 30 min, 1 h, or 4 h from the popup. Optional active hours.

**Posture checker (`checker/`)**
- MediaPipe Holistic (bundled locally, no network calls) finds your elbow and 21 hand points.
- Forearm axis = elbow to wrist. Hand axis = wrist to middle-finger knuckle.
- The angle between them is the wrist bend. Side view measures extension/flexion; top view measures ulnar/radial deviation.
- Calibrate with a straight wrist to remove camera and anatomy offset.
- Zones use Keir et al. (2007): caution past the 25 mmHg angle, high past the 30 mmHg angle.
- Alerts after 5 s in the high zone. Sessions are saved to history.

## Accuracy and limits

- A single webcam sees a 2D projection. Each view measures one plane, and accuracy drops if the forearm points toward the camera.
- On synthetic test images with known 20° to 40° bends, measured angles were within about 5°. This is not a clinical measurement.
- The side view assumes palms face down, as when typing.
- Safari needs Xcode conversion (`xcrun safari-web-extension-converter`) and has not been tested.

## Project structure

```
extension/
  manifest.json        MV3 manifest
  background.js        reminder engine (service worker)
  popup.*              toolbar popup
  break.*              guided break window
  dashboard.*          Today, Exercises, Posture, Research, History, Settings
  shared/              config (defaults + thresholds), exercises, storage, styles
  checker/             posture checker + angles.js (pure math) + vendor/holistic
web/                   standalone checker site (generated by build.sh, not committed)
tests/                 unit tests and syntax check (npm test)
.github/workflows/     CI tests and GitHub Pages deploy
research/              research PDF
build.sh               rebuilds web/ and dist/ zips
```

## Privacy

Everything stays on your device. No accounts, no analytics, no network requests. History is kept for 90 days in local browser storage and can be exported or cleared.

## Not medical advice

See a clinician for numbness or tingling that lasts, symptoms that wake you at night, weakness, or worsening pain.
